## homebox

家庭网络工具箱 / LAN speed test server (Rust backend with the web UI embedded
into the binary).

Upstream: [XGHeaven/homebox](https://github.com/XGHeaven/homebox) (MIT).
Built from source, so `node/host` and `rust/host` are pulled in as host build
dependencies and the first compile takes a few extra minutes.

👻 Powered by [XGHeaven](https://github.com/XGHeaven)
